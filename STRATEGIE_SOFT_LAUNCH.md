# STRATEGIE DE SOFT LAUNCH — Strategie & Expertise Sante

> Lancement progressif, maitrise et premium.
> Objectif : ouvrir les premieres ventes de maniere controlee avant ouverture large.

---

## PHASE 1 — Ouverture Controlee (J1 a J7)

### Objectif
Valider le pipeline complet en conditions reelles avec un volume restreint.

### Actions
1. **Activer le mode "Controle"** via le dashboard admin
   - Les commandes sont acceptees mais la surveillance est renforcee
2. **Premiers paiements live** — 3 a 5 dossiers max par jour
   - Privilegier des dossiers simples (AT, MP classiques)
   - Si possible, solliciter des clients "pilotes" bienveillants
3. **Monitoring quotidien obligatoire**
   - Verifier chaque matin les KPIs du monitoring live
   - Traiter immediatement tout incident
   - Verifier chaque email client recu
4. **Garder la main**
   - Si un probleme survient, passer en mode "Indisponible" immediatement
   - Corriger, puis re-ouvrir

### Criteres de passage a la Phase 2
- [ ] 5+ dossiers livres sans incident
- [ ] Taux de reussite > 90%
- [ ] Aucun incident non resolu
- [ ] Feedback client positif (ou neutre minimum)
- [ ] Delai moyen de livraison < 30 minutes

---

## PHASE 2 — Stabilisation (J8 a J21)

### Objectif
Confirmer la fiabilite sur un volume croissant et ajuster si necessaire.

### Actions
1. **Augmenter progressivement le volume** — 5 a 15 dossiers par jour
2. **Observer les patterns**
   - Pic de demandes a certaines heures ?
   - Types de dossiers problematiques ?
   - Delais de generation anormaux ?
3. **Ajustements rapides**
   - Optimiser les prompts si certains types de dossiers sont sous-performants
   - Ajuster les timeouts si necessaire
   - Ameliorer les emails si feedback client negatif
4. **Validation qualite continue**
   - Relecture aleatoire de 20% des rapports generes
   - Comparaison avec le standard V2 Premium valide

### Criteres de passage a la Phase 3
- [ ] 30+ dossiers livres sans incident majeur
- [ ] Taux de reussite stable > 95%
- [ ] Aucune plainte client
- [ ] Pipeline stable sur 7 jours consecutifs
- [ ] Monitoring KPIs dans les normes

---

## PHASE 3 — Ouverture Large (J22+)

### Objectif
Ouverture commerciale complete avec confiance technique validee.

### Actions
1. **Passer en mode "Ouvert"** definitif
2. **Activer la communication commerciale**
   - Landing page publique
   - Campagnes email
   - Referencement naturel
3. **Continuer le monitoring** — frequence hebdomadaire minimum
4. **Planifier les evolutions**
   - HubSpot CRM pour le suivi commercial
   - Nouvelles fonctionnalites IA

### Indicateurs de sante
- Taux de reussite > 95%
- Delai moyen < 15 minutes
- Incidents < 2% du volume
- Satisfaction client positive

---

## GARDE-FOUS PERMANENTS

| Situation | Action |
|-----------|--------|
| Incident sur 2+ dossiers consecutifs | Passer en mode "Indisponible" |
| Taux de reussite < 80% sur 24h | Passer en mode "Controle" |
| Quota Anthropic < 20 analyses | Alerte admin + recharge |
| Plainte client urgente | Traitement manuel prioritaire |
| Bug critique detecte | Mode "Indisponible" + correction |

## TIMELINE RESUMEE

```
J1-J7    : Phase 1 — Ouverture Controlee (3-5 dossiers/jour)
J8-J21   : Phase 2 — Stabilisation (5-15 dossiers/jour)
J22+     : Phase 3 — Ouverture Large (sans limite)
```
