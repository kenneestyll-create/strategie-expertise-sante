## VARIANTE 1 — « Analyse de dossier » (ancrage maladie professionnelle / accident du travail)

- **Title** (62 car.) : `Analyse de dossier maladie professionnelle — rapport sous 2 h`
- **Meta** (152 car.) : `Faites analyser votre dossier maladie professionnelle ou accident du travail : rapport personnalisé sous 2 h, jurisprudences et barèmes croisés — 97 €.`
- **H1** : `Faites analyser votre dossier accident du travail ou maladie professionnelle`
  (le sous-titre conserve la promesse : « rapport complet et personnalisé sous 2 h »)

| | |
|---|---|
| Requête principale | « analyse dossier maladie professionnelle » |
| Requêtes secondaires | « faire analyser son dossier accident du travail », « aide dossier maladie professionnelle », « aide dossier CPAM », « analyse dossier AT/MP en ligne » |
| Avantages SEO | S'ancre sur le mot-clé le plus fort du site (« maladie professionnelle » = cœur de l'autorité thématique existante) ; expression « analyse de dossier » = définition exacte du service = pertinence maximale ; cohérence totale avec les 7 pages piliers qui pointent déjà vers cette page. |
| Avantages conversion | « Faites analyser votre dossier » = injonction claire, le visiteur comprend l'offre en 1 seconde. |
| Inconvénients | Le cluster B (rapport d'expertise médicale) et le MDPH ne sont pas dans le title (ils seront couverts en H2/H3 + FAQ, signal plus faible) ; concurrence un peu plus dense sur « dossier maladie professionnelle » (pages CPAM, forums, avocats). |

## VARIANTE 2 — « Rapport d'expertise médicale » (niche ultra-qualifiée, différenciation produit)

- **Title** (62 car.) : `Faire analyser un rapport d'expertise médicale — avis sous 2 h`
- **Meta** (143 car.) : `Votre rapport d'expertise médicale analysé point par point : contradictions, taux IPP, stratégie de contestation. Rapport PDF sous 2 h — 97 €.`
- **H1** : `Faites analyser votre rapport d'expertise médicale`

| | |
|---|---|
| Requête principale | « faire analyser un rapport d'expertise médicale » |
| Requêtes secondaires | « deuxième avis expertise médicale », « contester rapport expertise médicale », « contre-expertise médicale prix », « analyse rapport médecin expert » |
| Avantages SEO | Intention la plus qualifiée des 5 clusters ; concurrence directe quasi nulle (les concurrents vendent la contre-expertise à 500-1 500 €, personne ne vend l'analyse à 97 €) ; colle à la vraie différenciation produit (comparaison multi-expertises, détection des contradictions — déjà mise en avant sur la page). |
| Avantages conversion | Visiteur en détresse aiguë post-expertise = décision d'achat rapide ; l'argument prix vs contre-expertise est massue. |
| Inconvénients | **Rétrécit la cible** : exclut du positionnement les dossiers MDPH, assurance et les MP/AT sans expertise (une partie des acheteurs actuels) ; volumes de recherche plus faibles ; risque de cannibalisation à piloter avec le pilier /expertise-medicale (gérable : intention « faire analyser » vs info, mais demande de la rigueur). |

## VARIANTE 3 — « Aide dossier » (couverture maximale + angle alternative avocat)

- **Title** (55 car.) : `Aide dossier CPAM, MDPH ou assurance — analyse sous 2 h`
- **Meta** (139 car.) : `Une aide concrète sans les honoraires d'un avocat : dossier analysé, stratégie et prochaines étapes. Rapport personnalisé sous 2 h — 97 €.`
- **H1** : `Une aide concrète pour faire avancer votre dossier`

| | |
|---|---|
| Requête principale | « aide dossier CPAM » |
| Requêtes secondaires | « aide recours MDPH », « aide contestation taux IPP », « aide litige assurance invalidité », « avocat maladie professionnelle prix » (via la meta « sans les honoraires d'un avocat ») |
| Avantages SEO | Couvre le plus de clusters à la fois (C, D, E) ; « aide » = le mot exact que tapent les victimes ; title le plus court (marque entièrement visible). |
| Avantages conversion | Registre émotionnel fort (« aide concrète ») ; l'angle anti-honoraires convertit bien les hésitants. |
| Inconvénients | « aide » est une intention parfois plus haute dans le funnel (curieux, pas acheteurs) → trafic moins qualifié ; **le title ne contient ni « maladie professionnelle » ni « analyse de dossier »** (les 2 signaux les plus forts) ; 3 organismes dans un title = dilution sémantique ; H1 sans mot-clé métier. |

---

## RECOMMANDATION (argumentée, décision vous appartient)
**Variante 1**, pour 3 raisons : (1) elle capitalise sur l'autorité thématique déjà construite (MP/AT = 100 % du maillage entrant existant) — c'est là que Google acceptera le plus vite de positionner la page ; (2) « analyse de dossier » est l'expression-miroir du service, imbattable en pertinence ; (3) elle ne sacrifie rien : les clusters B (rapport d'expertise), C (aide recours) et D (vs avocat) seront TOUS traités en H2/H3 + FAQ dans le corps du Lot A, quelle que soit la variante retenue — l'arbitrage ne porte que sur le trio title/meta/H1, c'est-à-dire la requête « étendard ».
Option hybride possible : title V1 + meta empruntant à V3 l'angle « sans les honoraires d'un avocat ».
